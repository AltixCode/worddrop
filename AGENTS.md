# WordDrop — agent manifest

Portfolio-wide rules live in `/Volumes/ExtremePro/Dev/AGENTS.md` and
`docs/agents/*.md` at that root. They apply here in full. This file records only
what is specific to WordDrop.

## Non-negotiables for this repo

1. **Nothing is faked.** A feature works on device or it does not exist — in
   code, in the UI, in `i18n`, in the store listing, or in a status report.
2. **Never hand-edit `ios/` or `android/`.** They are regenerated by
   `expo prebuild` on every CI run. Native changes go in `plugins/`.
3. **A build is not a verification.** `tsc`, `expo export` and `xcodebuild` all
   pass on an app that dies before its first frame. Launch it and drive the real
   flow (delivery playbook §15.4).
4. **No secret in the repo.** RevenueCat keys come from the environment, store
   credentials from GitHub Actions secrets.
5. **Unverified is `UNKNOWN`, never a pass** — in `HANDOFF.md` and in any report.

## Shape of the code

```
app/            Expo Router screens: index, game, result, stats, archive, settings, paywall
src/game/       Pure, fully tested logic — evaluateGuess, selection, streak, shareGrid, codec
src/data/       GENERATED. Rebuild with scripts/build-answers.mjs and build-dictionary.mjs
src/services/   purchases (RevenueCat), ads (AdMob + UMP), notifications, puzzleService
src/store/      Zustand + AsyncStorage; the persisted board holds the answer encoded
src/i18n/       14 locales in one file; every user-facing string goes through t()
backend/        Cloudflare Worker + KV: publishes one puzzle a day at 00:00 UTC
plugins/        Config plugins: iOS UIScene lifecycle, Android locales, Android RTL
```

## Rules the tests enforce, so do not work around them

- `src/game/*` stays pure and free of React Native imports; it is the part that
  is unit-tested, and the duplicate-letter case in `evaluateGuess` is the
  classic defect of this genre.
- The app and the Worker each hold a copy of the selection and codec logic
  (the app must work offline; the Worker cannot import the Expo bundle).
  `backend/test/parity.test.mjs` fails if they drift.
- `src/data/*.ts` is generated. Edit `answers.source.tsv`, then rebuild — CI
  compares the generated files against a fresh build.
- Adding an `i18n` key means adding it to all fourteen blocks;
  `scripts/check-i18n.mjs` fails on a partial set.

## Monetisation

Free with ads, removed by one lifetime non-consumable (entitlement `pro`).

- Never grant the entitlement when the SDK is not configured or the store is
  unreachable — `purchases.ts` returns a tagged union for exactly this reason.
- Never bake a price into a string. Read `product.priceString` from the offering.
- Ads: one interstitial a day, **after** the result screen, never between
  guesses; one anchored banner on the home and stats screens. A Pro player never
  initialises the ad SDK at all.

## Before committing

```bash
npm run verify     # typecheck, tests, i18n, UI rules, data drift, both exports, worker
```

`npm run verify` is gates 1–2 of the delivery playbook and nothing more. It
passes on an app that dies before its first frame; only a launch and a real
run-through of the game prove anything about the product.

Useful alongside it:

```bash
npm run schedule              # which answer lands on which day
npm run schedule -- --all     # the full review sheet, for the content pass
```
